# Screenshots

Drop the README screenshots in this folder using the exact filenames below, then
uncomment the matching `![...]` lines in [`README.md`](../../README.md) and
[`README.tr.md`](../../README.tr.md).

| Filename | Screen | Notes |
|---|---|---|
| `dashboard.png` | Dashboard | Active jobs, user counts, storage/usage cards |
| `bulk-operations.png` | Bulk Operations wizard | CSV-driven suspend/delete/signature push with progress |
| `signature-editor.png` | Gmail signature editor | WYSIWYG template editor with tokens |
| `onboarding.png` | Onboarding wizard | First-run setup (branding / Cloud project / Service Account) |

## Capture guidelines

- Use a **demo / placeholder organization** (e.g. "ABC Company") — never real
  customer names, real email addresses, or a real domain.
- Prefer the light theme for consistency unless showcasing dark mode.
- Target ~1600px wide PNG; keep files reasonably small (compress if large).
- Crop to the app window (no desktop background, no personal taskbar info).

> Tip: run the app with `npm run dev` and capture from the running window.
